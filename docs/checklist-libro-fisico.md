# Checklist del libro físico (edición de 1969)

Este checklist sirve para reconstruir el aspecto de la edición impresa y para
cotejarla con la tesis de 1967. No es necesario fotografiar el libro completo al
principio.

## 1. Datos físicos

- [ ] Alto de la cubierta, en milímetros
- [ ] Ancho de la cubierta, en milímetros
- [ ] Grosor aproximado del volumen, en milímetros
- [ ] Alto de una página interior, en milímetros
- [ ] Ancho de una página interior, en milímetros
- [ ] Una fotografía de una página con una regla visible
- [ ] Anotar si el libro abre completamente o si el lomo oculta parte del margen

## 2. Exterior y preliminares

- [ ] Cubierta
- [ ] Lomo
- [ ] Contracubierta
- [ ] Portada interior
- [ ] Reverso de la portada
- [ ] Página de créditos editoriales
- [ ] Dedicatoria, prólogo o agradecimientos, si existen
- [ ] Todas las páginas del índice

## 3. Muestra del diseño

- [ ] Primera doble página de la Introducción
- [ ] Una doble página de texto corriente
- [ ] Una doble página con encabezados y números de página claramente visibles
- [ ] Comienzo de un capítulo
- [ ] Final de un capítulo y comienzo del siguiente
- [ ] Comienzo de una de las grandes partes del libro
- [ ] Una página casi vacía o de transición, si existe
- [ ] Última página de contenido
- [ ] Colofón, si existe

## 4. Contenido lingüístico representativo

- [ ] Primera página de «Transcripción fonética»
- [ ] Una página con muchos signos fonéticos y diacríticos
- [ ] Una página de fonética con ejemplos alineados o enumeraciones
- [ ] Una página de morfología
- [ ] Una página de sintaxis
- [ ] Una página de literatura oral
- [ ] Una página densa de «Cosas y palabras»
- [ ] Una página con varias notas al pie
- [ ] Una página de conclusiones
- [ ] Una página del apéndice
- [ ] Una página de bibliografía

## 5. Material gráfico

- [ ] Cada tipo distinto de mapa (una muestra inicial)
- [ ] Una página con figura o dibujo
- [ ] Una página con tabla o cuadro
- [ ] Una página donde texto e imagen compartan espacio
- [ ] Anotar si las ilustraciones están numeradas igual que en la tesis

## 6. Cómo hacer las fotografías

- [ ] Cámara paralela a la página, sin perspectiva oblicua
- [ ] Página completa, incluidos márgenes y número de página
- [ ] Luz uniforme y sin sombras sobre el centro del libro
- [ ] Resolución máxima de la cámara
- [ ] Sin filtros, recorte, compresión ni corrección automática posterior
- [ ] Fotografiar como doble página cuando interese comparar recto y verso
- [ ] Conservar los archivos originales y sus nombres

## 7. Cotejo entre libro y tesis

- [ ] Confirmar si coinciden los títulos y el orden de las partes
- [ ] Confirmar si coinciden los números de los parágrafos
- [ ] Registrar páginas añadidas, eliminadas o reorganizadas
- [ ] Registrar correcciones textuales introducidas en 1969
- [ ] Comparar el inventario de signos fonéticos
- [ ] Comparar mapas, figuras y pies
- [ ] Comparar notas al pie y bibliografía
- [ ] Crear correspondencia: página del libro / página impresa de la tesis / página del PDF

## 8. Estado editorial por página o bloque

Para cada bloque incorporado a la edición digital:

- [ ] OCR importado como borrador
- [ ] Estructura y parágrafos identificados
- [ ] Cotejado con la tesis escaneada
- [ ] Cotejado con el libro de 1969
- [ ] Texto castellano revisado
- [ ] Formas pasiegas revisadas
- [ ] Notación fonética original revisada
- [ ] Correspondencia IPA revisada
- [ ] Notas, figuras y referencias comprobadas
- [ ] Compilación visual comprobada
